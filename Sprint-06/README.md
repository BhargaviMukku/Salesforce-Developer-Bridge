## 🛠 Key Concepts Learned

### Event-Driven Programming

Salesforce automatically responds whenever important business events occur.

Examples include:

- New Student Registration
- Job Posting Creation
- Application Submission
- Interview Status Update
- Offer Acceptance

---

### Why Automation?

Automation helps by:

- Reducing manual work
- Eliminating repetitive tasks
- Preventing human errors
- Improving business efficiency
- Ensuring consistency

---

### Apex Triggers

A Trigger executes automatically when records are:

- Inserted
- Updated
- Deleted
- Restored

Triggers help automate business logic without user intervention.
