# 🚀 Salesforce Sprint 9 – Building User Experiences with Lightning Web Components

## About This Sprint

Sprint 9 introduced me to the world of **Lightning Web Components (LWC)** and helped me understand how users interact with the Salesforce applications that we build. In previous sprints, I learned about Apex, SOQL, DML, Triggers, Bulkification, and Asynchronous Apex. This sprint connected all of those backend concepts to a user-friendly interface.

One of the biggest lessons from this sprint was that users do not care about Apex classes, SOQL queries, or database architecture. They care about completing a task easily and efficiently. Lightning Web Components help bridge the gap between complex business logic and a simple user experience. :contentReference[oaicite:0]{index=0}

## Key Takeaways

One of the most important lessons I learned is that **components represent user capabilities**. Instead of creating a large component that does everything, it is better to create smaller components that solve specific user needs. :contentReference[oaicite:3]{index=3}

I also learned how a simple user action, such as clicking an **Apply** button, can trigger multiple layers of processing behind the scenes. The request flows through the LWC, Apex, Service Layer, Business Rules, and Salesforce Data before returning a result to the user. :contentReference[oaicite:4]{index=4}

Another valuable lesson was understanding the importance of component communication and designing reusable interfaces that remain easy to maintain as applications grow.
